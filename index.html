Privacy Policy

Last updated: June 7, 2026

1. Introduction

This Privacy Policy explains how BotProtect ("the Bot", "we", "us") collects, uses, and protects information when you use our Discord bot. By using BotProtect, you agree to the practices described in this policy.

2. Data We Collect

BotProtect collects and stores the following data solely for the purpose of providing its features:

  • Discord User IDs – for moderation logs, warnings, economy systems, leveling, tickets, and user-specific configurations
  • Discord Guild (Server) IDs – for server-specific settings, prefixes, and configurations
  • Discord Channel and Message IDs – for logging, ticket systems, suggestion systems, and message tracking features
  • Role IDs – for autorole, temporary roles, and reaction role configurations
  • Message Content – processed in real-time for command execution (prefix-based commands). Message content is not permanently stored except for specific features where explicitly configured (such as suggestion logs, modmail transcripts, and warning reasons).
  • Voice State Information – for voice moderation and temporary voice channel features

3. How We Use Your Data

All collected data is used exclusively to provide and improve the Bot's functionality:

  • Server configuration and prefix management
  • Moderation features (warnings, bans, kicks, anti-raid)
  • Leveling and economy systems
  • Ticket and suggestion systems
  • Logging and audit features
  • Welcome and goodbye messages
  • Giveaway management
  • Temporary roles and voice channels
  • Invite tracking

4. Data Storage and Security

  • Data is stored in a secured MySQL/MariaDB database
  • We implement reasonable security measures to protect your data
  • Data is hosted on private servers with restricted access
  • We do not share, sell, or transfer your data to third parties
  • We do not use data for machine learning or AI training

5. User Rights and Control

  • Server Administrators can request deletion of all server-related data by contacting us
  • Users can request deletion of their personal data at any time
  • Kicking or banning the Bot from your server will stop data collection, but existing data will remain unless deletion is requested
  • You can opt out of certain features by disabling specific Bot modules in your server settings

6. Data Retention

Data is retained for as long as the Bot remains in your server or until deletion is requested. When the Bot is removed from a server, server-specific data may be retained for up to 30 days before automatic cleanup, unless deletion is explicitly requested sooner.

7. Message Content Handling

BotProtect processes message content in real-time to respond to prefix-based commands (e.g., +help, &kick). Message content is not permanently logged or stored, except for specific features where users explicitly configure message logging (such as suggestion channels, modmail transcripts, or warning logs). The Message Content Intent is required for the Bot's core functionality.

8. Third-Party Services

The Bot uses the following third-party services:

  • Discord API – for all core functionality
  • MySQL/MariaDB – for data storage

We do not use any analytics, advertising, or tracking services.

9. Changes to This Policy

We may update this Privacy Policy from time to time. We will notify users of any changes by updating the "Last updated" date at the top of this policy. Continued use of the Bot after changes constitutes acceptance of the updated policy.

10. Contact Information

For any questions, concerns, or data deletion requests, please contact us:

  • Discord: Join our support server (link available in the Bot's profile)
  • Email: 2bnp@selfbot.fr
