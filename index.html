Privacy Policy

Last updated: July 29, 2026

1. Introduction

This Privacy Policy explains how BotProtect ("the Bot", "we", "us") collects, processes, stores, and protects information when it is used within a Discord server. By using BotProtect, you acknowledge the practices described in this policy.

2. Data We Collect

BotProtect may collect and process the following Discord API data when necessary to provide its features:

  • Discord User IDs, usernames, and display names – for moderation, permissions, blacklists, tickets, levels, warnings, and user-specific features.
  • Discord Guild (Server) IDs – for server-specific settings, prefixes, security modules, permissions, and configurations.
  • Discord Channel, Role, and Message IDs – for logging, role management, tickets, suggestions, sticky messages, reminders, and other configured features.
  • Message content – for prefix-based commands, automated moderation, anti-spam, anti-link, anti-scam, bad-word filtering, honeypot channels, automatic replies, message logs, and optional AI features.
  • Command usage data – including command names, command arguments, user IDs, channel IDs, server IDs, execution status, and timestamps.
  • Member information – including join, leave, role, and member-update events required for welcome messages, automatic roles, moderation, blacklists, member counters, and anti-raid protection.
  • Presence information – processed in real time for optional support-status roles and aggregate online-member counters.
  • Voice state information – for voice moderation, voice logs, and temporary voice-channel features.

3. How We Use Data

Collected data is used to operate BotProtect features, including:

  • Server configuration and prefix management
  • Moderation, warnings, bans, kicks, and anti-raid protection
  • Spam, scam, phishing, toxic-content, and NSFW detection
  • Welcome and leave messages
  • Automatic, temporary, reaction, and support-status roles
  • Member and online-member counters
  • Tickets, suggestions, giveaways, reminders, and custom commands
  • Message, moderation, command, server, role, and voice logs
  • Security auditing, debugging, and abuse prevention
  • Optional AI-assisted moderation and AI commands

4. Message Content Handling

BotProtect processes message content to recognize configurable prefix-based commands and provide automated moderation features. Ordinary messages are not archived as a complete message history.

Command names and arguments may be stored in secured command logs for auditing, debugging, abuse prevention, and administrative purposes. Message content may also be retained when a server administrator explicitly enables features such as message logs, suggestions, modmail, warning reasons, sticky messages, reminders, custom commands, or similar functionality.

When optional AI-assisted moderation or AI commands are enabled, eligible message content may be transmitted to an external AI inference provider, such as Groq, Mistral, or Cerebras. These providers process the content to generate a response or moderation classification.

BotProtect does not use Discord message content to train its own machine-learning or artificial-intelligence models. Processing by external providers is subject to their respective privacy and data retention policies.

5. Presence Data

Presence information is processed in real time for optional support-status roles and aggregate online-member counters. BotProtect does not create permanent presence histories and does not permanently store custom statuses or user activities.

Users can opt out of the support-status role feature by removing the configured phrase from their custom status. Server administrators can disable the feature at any time.

6. Data Storage and Security

  • Stored data is kept in a secured MySQL/MariaDB database.
  • Access to the database is restricted to authorized operators.
  • Database credentials and API keys are not publicly exposed.
  • Stored data is protected using encrypted storage at rest.
  • Reasonable technical measures are used to prevent unauthorized access, disclosure, alteration, or destruction.
  • We do not sell personal data.
  • Data is only shared with service providers when necessary to operate requested BotProtect features.

7. Data Retention

Server configurations, member information, moderation records, and command logs may be retained for longer than 30 days while BotProtect remains in a server or until deletion is requested.

When BotProtect is removed from a server, server-specific data may be retained for up to 30 days for recovery, security, and technical purposes before deletion, unless deletion is requested sooner. Some records may be retained longer when required for security, legal compliance, or abuse-prevention purposes.

8. Third-Party Services

BotProtect uses the following service providers:

  • Discord API – for all Discord-related functionality.
  • MySQL/MariaDB – for secured application data storage.
  • Groq – for optional AI inference and moderation.
  • Mistral – as an optional or fallback AI inference provider.
  • Cerebras – as an optional or fallback AI inference provider.

Message content is only transmitted to AI providers when a relevant AI-powered feature is enabled or explicitly requested. We do not use analytics or advertising services to track users.

9. User Rights and Data Deletion

  • Users may request deletion of data associated with their Discord account.
  • Server administrators may request deletion of data associated with their Discord server.
  • Requests are processed after verification of the requester's identity or authority over the relevant account or server.
  • Removing BotProtect from a server stops new data collection from that server.
  • Server administrators can disable optional BotProtect modules at any time.

To request access to or deletion of your data, contact: 2bnp@selfbot.fr.

10. Children's Privacy

BotProtect is intended for use on Discord and is not directed at individuals who are not old enough to use Discord under Discord's Terms of Service. We do not knowingly collect information from individuals who are prohibited from using Discord.

11. Changes to This Policy

We may update this Privacy Policy when BotProtect's features or data practices change. The updated date at the top of this page will be changed whenever a revision is published.

12. Contact Information

For privacy questions, concerns, or data-deletion requests, contact:

  • Email: 2bnp@selfbot.fr

Résumé de la politique de confidentialité

BotProtect traite les identifiants Discord, les configurations de serveur, les informations de modération et certains contenus de messages afin de fournir ses commandes et ses fonctions de protection.

Les noms et arguments des commandes peuvent être conservés dans des journaux sécurisés. Lorsque les fonctions d'intelligence artificielle sont activées, certains messages peuvent être transmis à Groq, Mistral ou Cerebras afin de produire une réponse ou une classification de modération. BotProtect n'utilise pas ces messages pour entraîner ses propres modèles.

Les utilisateurs et administrateurs peuvent demander la suppression de leurs données en écrivant à 2bnp@selfbot.fr.
